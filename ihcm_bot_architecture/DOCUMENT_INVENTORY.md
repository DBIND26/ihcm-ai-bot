## Priority Order For Creation

Create in this order:

1. core docs
2. role playbooks
3. workflow templates
4. building profile for each building
5. payer and MDS reference guides
6. example outputs
7. intelligence generation

## Document Quality Standard

Each document should be:

- plain language
- explicitly approved or draft-labeled
- short enough to retrieve effectively
- updated by a named owner
- written to support a real decision or workflow, not just describe concepts
